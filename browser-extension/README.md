# 浏览器素材收集插件

适用于 Chrome 与 Edge。插件只扫描你当前打开的网页，勾选后将可读取的图片、视频保存到本机项目的“素材库”，并记录网页标题、平台和原页面地址。它不登录平台，也不自动遍历页面。

## 安装

1. 先启动本地项目并登录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开“开发者模式”，选择“加载已解压的扩展程序”，指向本目录 `browser-extension`。
4. 在项目“素材库”点击“连接浏览器插件”，复制显示的配对码；在插件中输入。配对码五分钟内有效。
5. 打开要收集的网页，点击浏览器工具栏中的插件图标，勾选素材后点击“保存选中素材”。返回素材库点“刷新”即可查看。

## 使用边界

- 插件需要读取网页及所选媒体地址的权限，连接本地服务使用 `127.0.0.1:1314`。采集令牌只允许导入素材，有效期 30 天；失效后重新配对。
- 平台可能限制媒体直链、使用加密播放或把视频拆成多个片段。此时会显示失败，不会谎报为已保存。视频或图片单个文件最大 100MB。
- 插件仅读取当前页面已经加载的媒体。淘宝、京东等列表页可滚动加载后点击“重新扫描”；平台页面结构变化可能影响结果。
- 请只保存你有权使用的素材，发布前确认图片、视频的授权情况。
